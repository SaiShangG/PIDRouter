# 高亮流路软件用户需求规格说明书（URS）

## 1. 文档目的

本文档用于定义 P&ID 高亮流路软件的用户需求，包括图纸导入、流路高亮、设备交互、阶段管理、报告生成及阀门矩阵输出等功能。

## 2. 责任方

| 责任方 | 职责 |
| --- | --- |
| PHS | 确保输入的 P&ID 图纸符合软件处理要求 |
| ROCKWELL | 提供并实现本文件规定的软件功能 |

## 3. P&ID 图纸前置要求

PHS 应确保提供的 P&ID 图纸满足以下条件：

1. 所有设备、仪表、管线及远程连接点使用正确的位号（Tag）。
2. 对象模型以块（Block）形式创建。
3. 所有管线均首尾连接（Glued End-to-End），不存在非预期断点。
4. 所有管道均具有流向箭头。
5. 远程连接（Distant Connection）使用唯一位号。

## 4. 功能需求

### 4.1 图纸导入与管理

- 软件应支持上传 AutoCAD、Plant 3D 和 COMOS 图纸文件。
- 用户应能够将任意图纸复制到下一阶段，并保留上一阶段的全部高亮状态，直至用户主动修改。
- 用户应能够按需重命名下一张图纸。
- 新建阶段时，用户应能够选择以下任一方式：
  - 使用上一阶段的已标记图纸，例如以阶段 21 创建阶段 22。
  - 使用任意历史阶段的已标记图纸，例如以阶段 4 创建阶段 24。
  - 使用一张新图纸。

### 4.2 管道与流路高亮

- 软件应根据远程连接点的对应唯一位号，跨远程连接继续高亮管道。
- 当管线存在断点时，用户应能够通过右键手动高亮管道。
- 高亮流路应能够跨 P&ID 页面延续，例如从第 1 页继续到第 2 页。
- 同一管线应支持使用不同颜色表示不同流向或用途，例如空气入口和空气排放使用不同颜色。
- 不同公用工程介质（Utility）应支持使用不同颜色显示。
- 只有高亮路径应醒目显示，其余内容应以灰色或黑色弱化显示。
- 每个循环步骤应具有独立的流路高亮状态。
- 需要打开的手动阀应在流程图（PFD）中以独立、醒目的方式标识。

### 4.3 阀门操作

- 所有阀门的右键菜单应提供以下操作：
  - `ON`（打开）
  - `OFF`（关闭）
  - `Pulse`（脉冲）
- 用户选择操作后，阀门应使用对应颜色显示其状态。
- 管道应从该阀门开始高亮，直至遇到下一个阻断元件。

### 4.4 电机类设备操作

- 所有电机类设备，包括搅拌器、泵、混合器、均质机和胶体磨等，其右键菜单应提供：
  - `START`（启动）
  - `STOP`（停止）
- 用户选择操作后，设备应使用对应颜色显示其状态。

### 4.5 其他工艺设备高亮

以下设备应支持按需高亮：

- 空气过滤器、液体过滤器、Midisart 过滤器、屏障过滤器及胶囊过滤器等滤芯或过滤组件
- 疏水阀
- 冷凝器
- 换热器
- 旋风分离器
- 排气加热器
- 消音器

### 4.6 传感器操作

- 所有传感器的右键菜单应提供：
  - `CONTROL`（控制）
  - `MONITOR`（监视）
  - `MONITOR & CONTROL`（监视并控制）
- 用户选择操作后，传感器应使用对应颜色显示其状态。
- 与传感器连接的虚线信号线应高亮至其所连接的组件。

### 4.7 容器液位或体积显示

- 软件应能够显示容器中的物料体积或液位。
- 容器内的体积应通过彩色填充方式直观表示。

### 4.8 文本与步骤条件

- 用户应能够在图纸中添加文本，尤其用于补充人工操作步骤。
- 在指定序列的指定步骤中，软件应能够以对话框形式显示相关联锁或步骤条件。
- 可关联的对象应包括压力变送器（PT）、温度变送器（TT）、控制阀、混合器等仪表或设备。

### 4.9 循环、阶段与步骤导航

- 在开始任意循环前，软件应首先显示所选循环包含的全部步骤。
- 对于集成式 P&ID，用户应能够通过步骤下拉选项浏览指定容器或撬装设备所属循环中的任意步骤。
- 流路 PDF 中应明确标注循环（Cycle）和阶段（Phase）。

### 4.10 PDF 报告

- 软件应能够按时间或步骤顺序生成从开始到结束的完整流路 PDF 报告。
- 报告应支持以下输出方式：
  - 所有序列和阶段合并为一个 PDF，例如 14 个序列、每个序列 30 个阶段，共生成一个 420 页 PDF。
  - 每个序列单独生成一个 PDF，例如生成 14 个文件，每个文件 30 页。
- 用户应能够删除报告中的指定页面，并在相同位置插入替换页面，例如替换第 390 页，而不影响其他页面。

### 4.11 阀门矩阵

软件应能够根据高亮流路生成阀门矩阵。矩阵应按序列和阶段至少包含以下信息：

1. 打开的阀门及脉冲阀门。
2. 处于 `ON` 或运行状态的电机类设备，包括搅拌器、泵、混合器、均质机和胶体磨等。
3. 激活的传感器及其模式：`CONTROL`、`MONITOR` 或 `MONITOR & CONTROL`。
4. 转入下一阶段的转换条件或动作。

## 6. 术语说明

| 术语 | 说明 |
| --- | --- |
| P&ID | 管道及仪表流程图（Piping and Instrumentation Diagram） |
| PFD | 工艺流程图（Process Flow Diagram） |
| Cycle | 循环或工艺循环 |
| Phase | 循环中的阶段 |
| Sequence | 由多个阶段组成的工艺序列 |
| Distant Connection | 用唯一位号关联不同位置或页面管线的远程连接点 |
| Valve Matrix | 按序列和阶段汇总阀门、设备、传感器状态及转换条件的矩阵 |

## 7. 待确认事项

以下内容建议在详细设计或验收标准制定阶段进一步确认：

1. AutoCAD、Plant 3D 和 COMOS 支持的具体文件格式及版本。
2. 各类设备状态、介质和高亮路径对应的颜色规范。
3. “下一个阻断元件”的设备类型及流路终止判定规则。
4. 管线断点的识别方式及手动高亮后的连接范围。
5. 跨页和远程连接位号的匹配规则，包括重复、缺失或错误位号的处理方式。
6. PDF 页面尺寸、页眉页脚、命名规则、排序规则及最大页数。
7. 阀门矩阵的字段、文件格式及导出模板。
8. 容器体积的数据来源、单位、量程及填充比例计算方式。
9. 用户权限、操作记录、版本管理及审批流程。
